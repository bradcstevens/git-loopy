Can an explicit publication promise keep a public tag immutable?

Drive this model to test whether a release can be completed only after its promised evidence is read back from the public remote. It separates a source-only promise (notes and source only) from an artifact-bearing promise, so neither a published tag nor its release contract can quietly change later.

The seven canonical archives: macOS arm64/x64, Linux arm64/x64, Windows arm64/x64, and universal source. Artifact-bearing prereleases require all seven archives, their checksums, and their release-channel trust receipts (not package channels) to be read back. Stable releases require those plus signature, notarization, publisher, and attestation evidence—there is no bypass.
