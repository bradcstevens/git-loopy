# git-loopy 0.11.0-dev.2

This development prerelease includes `v0.11.0-dev.1` and the completed Static
route execution work in #560. Together, these snapshots contain all completed
work since `v0.10.0`: #508, #510, #529, #530, #531, and #560.

The wizard-first setup, safer installation lifecycle, and discoverable commands
are described in the [previous development notes](https://github.com/bradcstevens/git-loopy/releases/tag/v0.11.0-dev.1).

## Static routes reach the work that actually runs

The Python Runner now preserves `route_policy` when handing a terminal Run to
its detached worker. A selected Static route therefore remains selected during
actual session execution, rather than silently reverting to the default policy
after the parent's preflight (#560).

A Static route with the `github-actions` Execution host is explicitly refused
before work starts. A capability listing from the operator's local authenticated
harness cannot prove what the remote runner's different installation supports.
Malformed or unavailable capability listings also fail explicitly, with their
underlying diagnostic reported instead of an unexplained fallback.

## Source-only availability and installation

This is a development prerelease, not a stable Promotion. It publishes committed
notes and GitHub's automatic source archives, without package-channel updates or
compiled TUI helpers. The Python Runner retains its line-printer fallback when
no compatible helper is installed.

Install or replace the user-global Python Runner with Python 3.11 or newer:

```sh
uv tool install --force "git+https://github.com/bradcstevens/git-loopy@v0.11.0-dev.2#subdirectory=git-loopy/python"
```

Use the explicit development tag: an unqualified `git-loopy upgrade` selects
the latest stable Release, not this prerelease.
