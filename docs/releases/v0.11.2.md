# git-loopy 0.11.2

git-loopy 0.11.2 is the patch Release after
[v0.11.1](https://github.com/bradcstevens/git-loopy/releases/tag/v0.11.1). It is
cut from the complete `main` snapshot and carries everything merged since
`v0.11.1`, ending with the Copilot SDK upgrade to `1.0.17rc5`.

The milestone-driven Promotion could not cut this Release. `release-promotion.yml`
refuses to run without the release-smoke credential and limits, and the repository
does not configure them. The operator authorized a direct promotion by exception,
the same path `v0.11.1` took. The tag still goes through `source-release.yml`'s
Runner-family Conformance gate and source-archive identity checks.

## Before you upgrade

- **The Copilot SDK pin is still a prerelease.** The Python Runner now pins
  `github-copilot-sdk==1.0.17rc5` (from `1.0.17rc3` in `0.11.1`), which runs
  Copilot CLI `1.0.92-5`. The model roster's provenance is restamped to that
  CLI. A live capture through it changed no effort set or context tier
  ([ADR-0019](../adr/0019-roster-derived-from-the-pinned-harness.md)).
- **The Wrapper contract moves from 2.23 to 2.26.**
- **Pickup never writes an inferred major Release-target label.** An issue the
  Runner would classify `major` now gets no `vX.Y.Z` label and reports
  `major_needs_human_label` instead. Only a human-applied label opens a major
  line ([ADR-0079](../adr/0079-a-human-opens-a-major-line-and-the-1-0-0-cut-waits-for-the-python-path.md), #755).
- **Releases remain source-only.** This Release publishes its GitHub source
  archives and these notes; no compiled `git-loopy-tui` helper or
  package-channel update is published with it (see
  [Distribution modes](README.md#distribution-modes)).

## What changed

### Runs, Pickup and Parallel mode

- **Ready Priority serial demand is honoured before new Lane reservations**
  (#720, #726). While a Priority issue waits for the serial path, Rolling
  dispatch reserves no new ordinary Lanes and drains the open cohort first
  ([ADR-0074](../adr/0074-the-serial-drain-waits-for-the-whole-lane-cohort.md)).
- **Lane retries are safe, and terminal accounting is precise** (#715).
  This remediates the review of the per-issue Rolling-dispatch retries
  shipped in `0.11.1`.

### Dashboard and Status

- **Each issue's Ending reaches the wire, and Queue Status is explained**
  ([ADR-0075](../adr/0075-a-status-says-what-happened-its-ending-says-why.md),
  #730, #736). A Status says what happened, and its Ending says why.
- **The Header shows the Serial drain** (#719, #727, #735): the wait since
  serial demand was raised, the age of the oldest open Lane, and the open
  cohort by phase.
- **Subagent lifecycle telemetry** is recorded and shown in the Header
  (#668, #710, #723).
- **A startup refusal is reported** when the Dashboard closes before the
  first Event (#737). Previously a bare `git-loopy` in a repository with no
  runnable feedback loop exited silently with a random status.
- **The Python replay oracle matches the Dashboard on Rolling dispatch** (#687,
  #711).

### Release-line assessment

- **An optional, read-only MCP server reviews a Release line** (#775, #776,
  #780, #781). It serves a fail-closed review packet, assesses counted checks
  at the pinned SHA, and reports whether a pinned assessment is still fresh.
  It is installed with the `assessment` extra.

### Skills and tooling

- **The Skill catalog pin moves to `d4b7315`**: `/model-fit` becomes
  `/set-task-models`, and `/model-scorecard` arrives (#743, #744, #749).
- **The TUI helper release pins `uv` and the Python minor** so cross builds
  stop failing on an unreleased interpreter (#721, #722).
- **Failing Attach tests leave no stand-in Run behind** (#739), and a flaky
  mixed-Priority Pickup test no longer asserts an order between concurrent
  Lanes (#741, #742).

### Decisions recorded

New ADRs record the 1.0.0 direction and planning model; none of them
changes shipped behaviour in this Release beyond the items above. They
include the Agent profile per Task type, the tracker as the board, the web
board as a loopback client, Completion proof for the 1.0.0 cut, and the Stable
surface 1.0.0 will promise. See [`docs/adr/`](../adr/).
