# git-loopy 0.10.0

git-loopy 0.10.0 begins with one deliberate, user-visible change: a Run on a
terminal now opens the live **Dashboard** by default instead of the line
printer. The Dashboard was already the live interface for an operator who knew
to install the terminal extra; making Textual a base dependency makes that
interface ordinary rather than conditional on an installation choice.

The Runner family is unchanged in shape — a Python reference Orchestrator,
native shell and PowerShell Orchestrators, and a Rust Dashboard core, all pinned
against the same Conformance fixtures.

## The live Dashboard is the terminal default

A terminal Run now takes the live **Dashboard** path by default. The line printer
remains available when it is the better fit: use `--no-interactive` or
`GIT_LOOPY_INTERACTIVE=0` to select it explicitly. A non-terminal Run continues
to use the line printer.
