# git-loopy 0.10.0

git-loopy 0.10.0 begins with one deliberate, user-visible change: a Run on a
terminal now opens the live **Dashboard** by default instead of the line
printer. The Dashboard was already the live interface for an operator who knew
to install the terminal extra; making Textual a base dependency makes that
interface ordinary rather than conditional on an installation choice.

The Runner family is unchanged in shape — a Python reference Orchestrator,
native shell and PowerShell Orchestrators, and a Rust Dashboard core, all pinned
against the same Conformance fixtures.

## The live Dashboard is the terminal default

A terminal Run now takes the live **Dashboard** path by default. The line printer
remains available when it is the better fit: use `--no-interactive` or
`GIT_LOOPY_INTERACTIVE=0` to select it explicitly. A non-terminal Run continues
to use the line printer.

## The run-wide default pair spends the ceiling

The **Default pair** — the model and reasoning effort a unit of work runs on when
nothing routed it — moves from `claude-opus-5 @ xhigh` to **`claude-opus-5 @ max`**
in all three Orchestrators and in this repository's own tracked Config
(ADR-0056, superseding ADR-0036).

ADR-0036 had held the default one rung below the ceiling so that `max` stayed
available as the **escalation rung**. ADR-0056 spends it instead: the first
attempt is the one that decides whether there is a retry at all, and a rung that
only pays out after a wasted session is worth less than the strength it withheld.

The cost is real and is recorded rather than hidden. The default pair now *equals*
the built-in escalation rung, so an **unclassified** issue that ends in silent
no-progress is retried at the identical pair — a no-op. Two things bound it:
every **Routed pair** still escalates for real, because no recommended route holds
`max` (ADR-0048); and `[escalation]` in either Config scope still names its own
rung, a cross-model pair being the obvious choice for anyone who wants a live
backstop for unclassified work.

The pair stays **atomic**: naming a model still opts out of the kit's effort, so
`GIT_LOOPY_MODEL=claude-opus-5` resolves to no effort at all rather than to `max`.
Operators who have run `git-loopy init` are unaffected until they re-seed — the
config-file tier wins over the built-in, as it always has.
