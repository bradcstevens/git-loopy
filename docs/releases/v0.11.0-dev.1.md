# git-loopy 0.11.0-dev.1

This development prerelease collects all completed work on `main` since
`v0.10.0`: #508, #510, #529, #530, and #531. It starts the next development
Release line; it is not a stable Promotion.

## Wizard-first setup

The fullscreen setup wizard is now the only interactive renderer. The numbered
setup and Skill pickers are removed, Textual is a base dependency, and the old
`[tui]` installation extra is no longer needed. Backward navigation and the
review-before-Save boundary remain available; non-terminal setup requires
`git-loopy init --yes` instead of piped numbered answers (#508).

The setup documentation now covers keyboard navigation, cancellation without
writes, unattended defaults, and the Dashboard default. Use `--no-interactive`
or `GIT_LOOPY_INTERACTIVE=0` to choose the line-printer view (#510).

## Safer installation lifecycle

`git-loopy uninstall` now completes its machine-local safety contract: it shows
the removal plan and requires confirmation, preserves repository contents and
Run logs by default, refuses live or unprovably dead Lane work, and checks that
removal paths have not changed since confirmation. Repository scope is included
only with explicit `--all`; a machine-local removal never takes the repository
with it. The associated Run lock no longer hangs or fails Runs on hosts that
cannot provide advisory locking (#529).

The operator reference distinguishes `update`, `upgrade`, and `uninstall`,
including their scope, flags, exit behavior, provenance safeguards, and refusal
paths. These management commands belong to the Python Runner; this Release does
not add them to the shell or PowerShell Orchestrators (#531).

## Discoverable commands

Root `--help` now groups management commands by category, `git-loopy help` is
its bare-word alias, and `git-loopy commands --json` exposes the same inventory
through a schema-versioned machine-readable surface (#530).

## Source-only availability and installation

This prerelease publishes committed notes and GitHub's automatic source
archives. It does not update package channels or publish compiled TUI helpers.
The Python Runner retains its line-printer fallback when no compatible helper
is installed.

Install or replace the user-global Python Runner with Python 3.11 or newer:

```sh
uv tool install --force "git+https://github.com/bradcstevens/git-loopy@v0.11.0-dev.1#subdirectory=git-loopy/python"
```

Use the explicit development tag: an unqualified `git-loopy upgrade` selects
the latest stable Release, not this prerelease.
