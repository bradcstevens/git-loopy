# git-loopy 0.11.0-dev.4

This source-only maintenance prerelease is based on `v0.11.0-dev.2`, not
`v0.11.0-dev.3`. It upgrades the Python Runner to
`github-copilot-sdk==1.0.13`, which is available through the Microsoft corporate
Python feed. SDK `1.0.14`, required by dev.3, was not available through that feed
when this release was prepared.

- Pin SDK `1.0.13` and its Copilot CLI `1.0.83` without upgrading unrelated
  Python dependencies.
- Accept SDK-provided Skills as the existing `custom` source kind while keeping
  closed-world exposure: a pathless provider Skill cannot be exposed to a Run.
- Refresh the roster against CLI `1.0.83`, including all 19 observed models.
  Retain seven documented historical compatibility rows without claiming they
  were offered to the account used for the refresh.
- Cover the installed SDK's client/session signatures, dependency-pin
  consistency, Skill discovery, and roster provenance with offline tests.
- Preserve dev.2's configured model choices and other behavior. The unrelated
  routing, Run-management, and release-rehearsal changes added in dev.3 are not
  included.

The published dev.2 and dev.3 tags are unchanged. This prerelease is published
from the `fix/dev2-sdk-1.0.13` maintenance branch and does not replace `main`.

Upgrade an existing uv-tool installation with:

```sh
git-loopy upgrade --to 0.11.0-dev.4
```

On corporate-feed machines, keep the Microsoft npm and Python feeds configured.
Development checkouts must export public lockfile pins locally and install them
through the corporate Python feed before using `uv run --no-sync`; do not sync
the lockfile's public artifact URLs.
