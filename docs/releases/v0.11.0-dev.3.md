# git-loopy 0.11.0-dev.3

This development prerelease includes the current `main` snapshot after
`v0.11.0-dev.2`, including the GitHub Copilot SDK upgrade in #594.

## Copilot SDK 1.0.14

The Python Runner now pins `github-copilot-sdk==1.0.14` and its managed Copilot
CLI `1.0.85`. Updating the separate `copilot` command on `PATH` does not change
the SDK's harness.

The upgrade handles the SDK's new Skill source without weakening the
closed-world Skill policy. Provider-backed Skills use the existing `custom`
source kind, and a pathless Skill still cannot enter isolated Skill exposure
unless the installed catalog supplies a filesystem-backed winner.

The model roster includes all 19 models observed through the pinned harness,
including GPT-6 Astra, GPT-5.6 Sol Fast, Grok 4.5/4.6, and MAI Code 1.1 Flash.
Seven existing compatibility entries remain unchanged and are explicitly
distinguished from the newly observed capabilities.

Saved model choices are preserved. Gemini 3.8 was not available in the
upgrade account's listing, so it receives no invented capability gate:
configured `gemini-3.8-flash` model and effort values retain the existing
warning-and-pass-through behavior.

## Other changes since dev.2

- Live-evidence routing, final-route publication, and reuse of freshly
  validated routing results (#561, #563, #565).
- Clone-scoped Run listing with platform-appropriate liveness reporting (#584).
- More accurate setup cancellation and blocked-startup diagnostics (#583).
- Exact promoted-snapshot rehearsal before creating a public stable tag (#587).

## Source-only availability and installation

This is a development prerelease, not a stable Promotion. It publishes
committed notes and GitHub's automatic source archives, with no compiled
TUI helpers or package-channel updates. Stable `v0.10.0` remains unchanged.

Install this prerelease with Python 3.11 or newer:

```sh
uv tool install --force "git+https://github.com/bradcstevens/git-loopy@v0.11.0-dev.3#subdirectory=git-loopy/python"
```

Use the explicit development tag: an unqualified `git-loopy upgrade` selects
the latest stable Release, not this prerelease.
